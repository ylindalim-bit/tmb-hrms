EPF

A percentage of the same EPF wage base as the statutory contribution (e.g. 2 = an extra 2%), on top of the statutory EPF rate. Deducted from the employee's net pay each month; the employer's statutory contribution is unaffected.

Date Joined and Last Working Day drive the mid-month proration for Basic Salary and Fixed Allowance (a new joiner or leaver only gets paid for the calendar days actually employed that month). Probation Period is just a shortcut — picking 3 or 6 months (or "Custom" to key in any number, e.g. 0, 1, 2) fills in Probation End Date from Date Joined; you can still edit it directly any time. Need to push it out with a tracked reason instead? Use Probation Extension right below. Work Pattern: set once here and every month's "Working Days in Month" on the Attendance page auto-fills for you (Mon-Fri or Mon-Sat count for that calendar month, public holidays already subtracted) — still editable per month if something's different. Leave as "Manual" for anyone with an irregular/alternating Saturday schedule, since that can't be predicted from a calendar alone.
